If a photo is ever removed or a new office bearer is added without one
yet, that card automatically falls back to a navy lettermark avatar
instead of breaking — no code changes needed either way.

Photos appear with a grayscale-to-colour hover effect and animate from a
small circular avatar to a larger one on hover, so any reasonably sharp,
evenly-lit headshot works well — no special cropping needed.
